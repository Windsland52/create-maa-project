# {{displayName}}

MaaFW project generated by create-maa-project.

## Development

The project entry configuration is `interface.json`; tasks live in `tasks/` and resources in `resource/`.

If `package.json` exists at the project root, the development tooling is enabled and you can run:

```bash
pnpm install
pnpm check
```

When you open the project in VS Code, `.vscode/tasks.json` automatically runs `pnpm install --frozen-lockfile`.

Otherwise, run `create-maa-project --add dev-tools` when you want formatting, validation, and editor setup.

## Release

If `.github/workflows/release.yml` exists, pushing a tag such as `v{{version}}` triggers a release.
Otherwise, run `create-maa-project --add github` to add CI and release automation.
